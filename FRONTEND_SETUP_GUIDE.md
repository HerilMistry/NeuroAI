# NeuroAI Frontend Setup & Integration Guide

## Quick Start (5 Minutes)

### 1. Start the Backend

```bash
cd /home/daddy/Downloads/MedGemma/neuroai2/NeuroAI/backend
pip install -r requirements.txt
python manage.py runserver 0.0.0.0:8000
```

The API will be available at: `http://localhost:8000/api/v1/`

### 2. Generate Frontend with Lovable

#### Option A: Use the Quick Prompt (Recommended)

1. Go to [Lovable](https://lovable.dev)
2. Create a new project or open chat
3. Copy-paste the entire contents of `LOVABLE_QUICK_PROMPT.txt` from this directory
4. Press Enter and let Lovable generate the frontend

#### Option B: Use the Detailed Prompt

1. Go to [Lovable](https://lovable.dev)
2. Copy-paste the entire contents of `LOVABLE_PROMPT.md` from this directory
3. Press Enter and let Lovable generate with detailed specifications

### 3. Configure the Generated Frontend

Once Lovable generates your project:

```bash
# Extract/download the project
cd neuroai-frontend

# Create .env file
cat > .env << 'EOF'
REACT_APP_API_BASE_URL=http://localhost:8000
REACT_APP_API_TIMEOUT=30000
REACT_APP_ENABLE_ANALYTICS=false
EOF

# Install dependencies
npm install

# Start development server
npm start
```

Frontend will open at: `http://localhost:3000`

### 4. Verify Integration

```bash
# Test API connectivity from browser console:
# Paste this in browser console:
fetch('http://localhost:8000/api/v1/system/')
  .then(r => r.json())
  .then(d => console.log(d))
```

If you see platform info, everything is connected!

## TypeScript Types (For Generated Frontend)

```typescript
// Define these types based on backend responses

interface Drug {
  id: number;
  drugbank_id: string;
  chembl_id: string;
  name: string;
  smiles: string;
  molecular_weight: number;
  logp: number;
  cns_mpo_score: number;

  pains_alerts: number;

interface Target {
  id: number;
  gene_symbol: string;
  gene_name: string;
  uniprot_id: string;
  protein_name: string;
  disease_relevance_score: number;
  is_toxicity_associated: boolean;
  brain_expression_level: string;
}

interface Pathway {
  id: number;
  pathway_id: string;
  name: string;
  category: string;
  disease_relevance: string;
  target_count: number;
}

interface DrugPathwayEffect {
  id: number;
  drug_name: string;
  pathway_name: string;
  pathway_category: string;
  perturbation_score: number;
  direction: "activation" | "inhibition" | "modulation";
  disease_impact: "beneficial" | "detrimental" | "unknown";
  confidence: number;
  has_safety_concern: boolean;
}

interface PredictionResult {
  status: "success" | "error";
  binding_affinity?: {
    target: string;
    binding_score: number;
    confidence: string;
  };
  toxicity?: {
    toxicity_risk: string;
    mechanism: string;
  };
}

interface SimulationResult {
  baseline: TrajectoryData;
  intervention: TrajectoryData;
  comparison: {
    improvement: string;
    pathway_impact: string[];
  };
  overall_assessment: string;
  caveats: string[];
}

interface TrajectoryData {
  label: string;
  trajectory: {
    time_step: number;
    parameters: Record<string, number>;
    uncertainty: number;
  }[];
  key_changes: string[];
  explanation: string;
}
```

## Common Frontend Patterns

### Fetching Drugs

```typescript
async function fetchDrugs(page = 1, filters = {}) {
  const params = new URLSearchParams({ page, ...filters });
  const response = await fetch(
    `${process.env.REACT_APP_API_BASE_URL}/api/v1/drugs/?${params}`,
  );
  if (!response.ok) throw new Error("Failed to fetch drugs");
  return response.json();
}
```

### Searching

```typescript
const [searchQuery, setSearchQuery] = useState("");
const results = await fetchDrugs(1, { search: searchQuery });
```

### Handling Predictions

```typescript
async function predictBinding(smiles: string, target: string) {
  const response = await fetch(
    `${process.env.REACT_APP_API_BASE_URL}/api/v1/predictions/binding-affinity/`,
    {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({
        molecule_smiles: smiles,
        target_name: target,
      }),
    },
  );
  return response.json();
}
```

### Running Simulation

```typescript
async function runSimulation(drugId: number, timeSteps = 10) {
  const response = await fetch(
    `${process.env.REACT_APP_API_BASE_URL}/api/v1/simulate/`,
    {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({
        drug_id: drugId,
        time_steps: timeSteps,
      }),
    },
  );
  return response.json();
}
```

## Troubleshooting

### Frontend Can't Connect to Backend

```bash
# Check backend is running
curl http://localhost:8000/api/v1/system/

# Check CORS (backend should allow requests from localhost:3000)
# In Django settings: ALLOWED_HOSTS = ['localhost', '127.0.0.1']

# Verify .env file has correct API URL
cat .env | grep REACT_APP_API_BASE_URL
```

### API Returns 404

```bash
# Verify endpoint URL
# All endpoints should be under /api/v1/
# Example: GET /api/v1/drugs/ (NOT /drugs/)

curl http://localhost:8000/api/v1/drugs/
```

### CORS Errors

```python
# In backend/neurodegenrx_backend/settings.py, add:
CORS_ALLOWED_ORIGINS = [
    "http://localhost:3000",
    "http://localhost:5173",  # Vite default
]
```

### Slow API Responses

```bash
# Check backend logs for errors
# Monitor database: sqlite3 backend/db.sqlite3

# If predictions are slow:
# - ML models load on first request
# - GraphDTA and MedGemma initialization takes ~10-15 seconds
# - Display loading indicator and set timeout to 60+ seconds
```
